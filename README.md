# Resume Screening System

## Project Overview

This is a complete, runnable **Intermediate** level data science project for **NLP Classification**. The dataset is synthetic but designed to look realistic enough for practice, portfolio demonstration, and educational explanation.

## Files Included

- `README.md` - project guide
- `description.md` - detailed project explanation and workflow
- `main.py` - standalone script to run the full pipeline
- `text_dataset.csv` - main dataset file
- `Resume Screening System.ipynb` - executed Jupyter Notebook with outputs and charts
- `Resume Screening System.pdf` - compact project report
- `charts/` - exported chart images generated by the notebook
- `requirements.txt` - Python dependencies

## Target / Output

`category`

## Notebook Workflow

1. Import libraries and configure the project.
2. Load the synthetic dataset.
3. Inspect rows, columns, missing values, and summary statistics.
4. Generate EDA charts.
5. Build the machine learning or analytics workflow.
6. Evaluate results with metrics.
7. Save charts and summary artifacts.

## How to Run

### Option 1: Standalone Python Script
```bash
pip install -r requirements.txt
python main.py
```

### Option 2: Jupyter Notebook
```bash
pip install -r requirements.txt
jupyter notebook "Resume Screening System.ipynb"
```

The notebook has already been executed and saved with its outputs.
